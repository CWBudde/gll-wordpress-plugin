# GLL Info documentation

Documentation for site owners and editors using the GLL Info plugin. No coding
knowledge is assumed.

| Document | What it covers |
| --- | --- |
| [getting-started.md](getting-started.md) | Uploading a `.gll` file and putting your first block on a page |
| [blocks.md](blocks.md) | Every block and every setting in its sidebar |
| [patterns-and-variations.md](patterns-and-variations.md) | The three ready-made layouts and the thirteen block presets |

Styling and theme integration are documented in the plugin's `readme.txt`, under
`== Theming ==`.

The `plans/` subdirectory holds design notes written for developers. It is not
user documentation.

## Status

This is version 0.1.0 and the plugin has not been released. Everything described
in these documents exists in the code, but the plugin has not been through a
release cycle, and some behaviour noted below is explicitly incomplete.
